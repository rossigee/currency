Lightning Network payment module for Odoo 16.

Provides comprehensive Lightning Network integration including:

* Lightning Service Provider (LND node) management with macaroon authentication
* Lightning address management with transaction history
* Professional payment processing with background job support
* Real-time BTC price integration and QR code generation
* Complete audit trail and state tracking
* Secure credential storage via vault connector

Features live payment request generation, status tracking (draft → pending → success/failed),
and full LND REST API integration for Lightning Network operations.
